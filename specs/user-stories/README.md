# User Stories — Übersicht und Nachverfolgung

Dieses Dokument gibt einen Überblick über alle User Stories von CaseFlow.

**Wie liest man dieses Dokument?**
- Die **Stories-Tabelle** listet alle Stories mit direktem Link zur Detaildatei.
- Die Szenarien in den Stories sind **fachliche Spezifikationen**, die gleichzeitig
  als automatisierte Tests (`src/test/resources/features/`) ausgeführt werden.

**Konventionen:** Dateiname `<issue-nr>-<slug>.md`, ID `US-<issue-nr>`.
Struktur je Story: Kopf-Tabelle (ID, Priorität, Schätzung, Issue), Beschreibung
(Als/möchte ich/damit), Scope, Akzeptanzkriterien, BDD-Szenarien, Aufgaben.
Die Skills `/task`, `/plan` und `/implement` legen Stories in diesem Format an.
